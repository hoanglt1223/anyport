# Phase 05: HLE BIOS

## Context

The GBA BIOS is copyrighted. Implementing its SWI functions natively removes the need for a BIOS file and is faster than running BIOS code. This is the GBA equivalent of AnyPS5's `prx` reimplementations.

## Requirements

- Native implementations of SWI 0x00-0x2A that games use: SoftReset, RegisterRamReset, Halt, Stop, IntrWait, VBlankIntrWait, Div, DivArm, Sqrt, ArcTan, ArcTan2, CpuSet, CpuFastSet, GetBiosChecksum, BgAffineSet, ObjAffineSet, BitUnPack, LZ77UnCompWram/Vram, HuffUnComp, RLUnCompWram/Vram, Diff8/16bitUnFilter, SoundBias, MidiKey2Freq, and the sound driver SWIs as logged stubs.
- Post-boot state as if the real BIOS ran: register values, SP per mode, IO defaults.
- BIOS-region reads return the values games observe after a SWI (some games read BIOS memory as an anti-piracy check).
- Unknown SWI numbers: log and throw, same strictness as AnyPS5.

## Files (create)

- `runtime/src/bios/swi_table.cpp`, `bios/math.cpp`, `bios/decompress.cpp`, `bios/memcpy.cpp`, `bios/affine.cpp`, `bios/boot_state.cpp`
- `tests/runtime/bios_tests.cpp`

## Steps

1. Implement the SWI dispatch table and boot state.
2. Implement math and memory functions, then decompressors, then affine helpers.
3. Return values and register side effects exactly as GBATEK documents (for example Div returns r0=quotient, r1=remainder, r3=abs quotient).

## Validation

- jsmolka `bios.gba` passes.
- Decompressor output matches reference data generated by `gbalz77` / GBA homebrew tools.

## Risks

- Undocumented register side effects games depend on. Compare against mGBA's HLE BIOS behaviour when a game misbehaves.

## Rollback

Isolated module; revert.
